Everything is a numbered .bat file. Double-click it. You never
need to open Python, and you never need to remember where a
file lives. The numbers will not change once you know them.

The two rules the whole suite is built on:

  1. ONE AREA FOR ALL THE EXCELS. Every workbook every report
     reads lives in Data\ - nothing reads from anywhere else.
     Fresh SiteIQ pulls get saved over the top of the same
     names in Data\ (or use button 12 to file them for you).
     The old copy is backed up into Data\previous\ first.

  2. WORKS ON ALL COMPUTERS. Copy this whole folder to any
     laptop and everything still works - every path inside the
     suite is relative to the folder itself. On a new machine,
     run 10_CHECK_MY_SETUP first and it will tell you in plain
     words if anything is missing.

------------------------------------------------------------
EVERY MORNING (about 10 minutes)
------------------------------------------------------------
  1. Download fresh SiteIQ exports (RENTAL_STOCK, STOCKTAKE,
     TRANSACTIONS), then double-click 12_PULL_SITEIQ_EXPORTS.
     It finds them in Downloads, checks they are AMPOL exports,
     backs up yesterday's copies and files the new ones into
     Data\. Wrong-site files are skipped loudly, never filed.
  2. If a report workbook needs a refresh (radio / tooling .xlsm),
     open it FROM Data\, press Refresh, save. The GAS report no
     longer needs its workbook refreshed - it counts everything
     from RENTAL_STOCK and TRANSACTIONS (02 Sep 2026).
  3. Double-click 00_RUN_EVERYTHING. It builds every report,
     makes the Outlook drafts and runs the final check.

Everything lands in Reports\(today's date)\ - one folder per
report family, dated, never overwritten.

------------------------------------------------------------
SENDING
------------------------------------------------------------
NOTHING SENDS BY ITSELF. EVER.

Every email lands as a DRAFT - either in Outlook Drafts (via
button 08 or the drafts step in 00) or as a .eml file in the
day's Reports folder you can double-click open. Read the
draft, check the numbers, press Send yourself.

Before sending, 09_CHECK_REPORTS sweeps every page built today
for blanks, leftover {placeholders}, nan and None, and weighs
every email against the 10 MB limit. Run it. It is the last
gate.

------------------------------------------------------------
WHEN SOMETHING IS WRONG
------------------------------------------------------------
Reports look wrong or thin:
  - Check the data first: are the files in Data\ today's pulls?
    The report footer shows "Data as at" - if it says
    yesterday, the export is yesterday's.
  - 10_CHECK_MY_SETUP names anything missing in plain words.

A button window flashes an error:
  - Run it again and read the message - every failure says
    what is wrong in plain words. If it names a missing file,
    that file belongs in Data\.

Outlook drafts did not appear:
  - Outlook (classic desktop) must be open. Run 08 again -
    already-drafted reports are skipped, nothing doubles up.
  - No Outlook on this machine? Create a file called
    NO_OUTLOOK.txt in this folder and 00 will skip drafting.
    The .eml files in the day's folder still work.

------------------------------------------------------------
HOUSEKEEPING
------------------------------------------------------------
Reports\ grows by one dated folder per day and nothing in it is
ever overwritten - that is the audit trail. Old days can be
moved into _Archive\ whenever the folder feels heavy. Never
prune Data\previous\ on a day a number is in dispute - it is
the proof of what the data said.
