# GC500 Race Control: concept (not built)

Author: Andrew Fisher · 2 Oct 2026

**Andrew's brief.** Merge Today and Where we are into one tab. He asked for:
- "a dashboard racecar feel look";
- "like inside the cockpit feel";
- "maybe the mp4 video could be treated as a rear mirror".

The first attempt simply stacked the two tabs on top of each other, and Andrew rejected it ("we need to go better").

**What this concept is.** A static picture made from the 2 Oct figures. The live page is unchanged. Open `race.html` in a browser to see it.

## The cockpit

| Part | What it is |
|---|---|
| Rear-view mirror | The Today MP4 banner, with Play with sound |
| Shift lights | Whole-job progress |
| Rev-counter | Deliveries due by today against the plan, with the on-track flag |
| Lap | Programme day |
| Gap to race | Days to race |
| Start lights | The lights counts |
| Binnacles | Fencing metres and revenue |
| Steering-wheel grip buttons | Switch between the four views below |

## The four views

| View | What it shows |
|---|---|
| **Race** | Pit board (the heads-up notes on an LED board), next programme day, delivery updates, team radio, records, Fencing, Costs, Map, Documents |
| **Trades** | By group, shown as 11 sectors |
| **Pit Wall $** | Revenue by stream, are we making money, by branch |
| **Telemetry** | Build, fencing planned vs done, demob, on site by date |

Nothing from either tab is dropped. Only the repeated gauge goes.
