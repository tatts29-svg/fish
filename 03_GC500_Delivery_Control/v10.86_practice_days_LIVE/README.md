## Why the codes are permanent
A code is `/d/<tracker token>#r=<REF>.<signature>~pump|~clean`. The signature is the service's own, per tracker and
reference. Updating the tracker (Create / update event tracker again, same token) keeps every printed code. Areas, maps,
wording, layout, practice days removed later: none of it changes a code. A third party can rebuild the sheets from
the private QR bundle with `servicing_tracker_DRAFT/print/make_sheets.py` and the codes stay the same.
