# Interaction and legibility checks

Author: Andrew Fisher.

Independent, GET-only browser checks. Detailed screenshots and model snapshots remain in private evidence storage. These scripts do not publish or write operational records.

`audit_flows1018.cjs` samples every declared route for contrast on measurable solid backgrounds, control clipping, horizontal overflow, disclosure persistence and scroll continuity. `FINAL=1 MOB=1` uses the shared phone profile at 390 × 844 and DPR 2. `FINAL=1` uses desktop 1440 × 1000 and 3840 × 2160. Final mode also checks canonical routes, seven deep links, browser Back and unchanged application/map input hashes. It reports direct `go()` duration separately from browser settling and inspection. Gradient/composited contrast is left for visual inspection.

`check_save1018.cjs` exercises a native selection Save under isolated document capture. Drafts remain explicitly unsaved; local persistence is distinguished from shared acknowledgement; failed persistence remains visible. It checks focus, disclosure and reading position through redraw and Save. The edit capability exists only in the isolated browser. All non-GET service requests remain blocked.

Set `PAGE`, private `OUT_DIR`, `CHROMIUM_PATH`, `NODE_PATH`, `HARNESS` and `MAP_CODE` as appropriate. Final checks use `map/tests/readonly1018.cjs`. Serialize browser runs with `/tmp/gc500-browser.lock`.

The profile/prototype scripts only wrap functions in memory and restore them. They compare rendered text and financial/unit models, without recording private figures in shareable output. They established two concrete bottlenecks: recursive supplier pricing through the customer docket projection, and repeated unit-model construction within one draw. Prototype timings are diagnostic measurements, not a universal response-time guarantee. Application fixes and final release verification are owned by the integration component.

Baseline review: 66 route/viewport samples and 49 continuity checks passed on the published v10.17 source. It reproduced a low-contrast arrival-plan link and small Equipment/Documents controls, passed to the presentation component. The initial combined candidate's native Save lifecycle passed all nine checks. Final exact-candidate route results are pending integration of the performance correction.
