# Pickup maps from Map Explorer

Author: Andrew Fisher.

Andrew asked to use the map he searches in, because separate arrows on the exported master drawing were confusing. Pickup PNGs and PDF location sheets now use the active Explorer map style and orientation, framed around the selected 50 m area. The same underlay, vector worker, satellite imagery, map registration and equipment label painter supply the picture. Clearly labelled pickup dots match the navigation destinations; recorded doors and truck loading remain in the written details.

DRAFT, not live. Base v12.14: `91f9006070d1269eb6e9ae807076e9146e7e52e6fbfc68a01d840f5666559a11`. Scope is the pickup-map renderer, PDF captions and prepared-pack freshness. No record, collection, quantity, price, ownership, navigation-target or tracker changes. Existing original area-share behaviour is outside this pickup-pack change.

Incomplete satellite imagery stops preparation with an explicit retry message; it never silently substitutes the original plan. The picture is rendered off-screen at 3840 pixels, so the camera and display canvases remain untouched. The three map modes, rotation, viewer preservation, navigation and PDF content need verification, plus the required desktop/phone navigation sweeps and visual inspection, before guarded publication.

Private PDFs, screenshots, map pictures and operational snapshots remain outside the repository. Only sanitised verification summaries belong here.
