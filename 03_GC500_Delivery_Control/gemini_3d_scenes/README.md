# Gemini 3D site scenes (prompts)

Author: Andrew Fisher

Andrew asked on 9 Oct 2026 for three prompts Gemini can use to build interactive 3D environments, "like our machine", based on what we do:
1. erecting fencing around the track;
2. levelling buildings;
3. unloading portable toilets.

## Files

| File | What it is |
|---|---|
| `1_fencing_prompt.md` | Scene 1: temporary fence run beside the circuit |
| `2_building_levelling_prompt.md` | Scene 2: tilt-tray unload, jack, pack and level a 6 m building, fit steps |
| `2plus_crane_truck_followup.md` | Follow-up for scene 2. Send it in the same chat once scene 2 works |
| `3_toilet_unloading_prompt.md` | Scene 3: forklift 8 of 24 toilets into rows with a separate spotter |
| `3plus_demob_followup.md` | Follow-up for scene 3. Demob: the pumped-out-before-loading gate |
| `gemini_site_scenes.html` | The same prompts on one page with copy buttons |

## How they were made

1. Three readers pulled facts from this repo: the Coates Way machine and Showcase (three.js r170, materials, controls), the install pre-start and site plans, and the delivery and demob rules.
2. The prompts were drafted from those facts.
3. They were fact-checked against the repo and reviewed for whether Gemini can build them first go.
4. The 44 issues raised were fixed.
5. The colours are the Coates brand: orange #F26222 on charcoal #1D1D1B, chosen by Andrew ("what ever u think").

## How facts are worded

- Facts that aren't in the repo are marked "typical".
- Game timings and scores are game settings, not site rules.
- The prompts carry no names, prices, phone numbers, job or docket numbers, or internal links, because Gemini is an outside service.

## Not yet tested

Nobody has run Gemini on these prompts yet.
