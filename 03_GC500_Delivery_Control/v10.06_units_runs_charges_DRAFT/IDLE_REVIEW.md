# Background drawer refresh

Author: Andrew Fisher

The v10.05 phone fixture reproduced an open physical-unit form collapsing and its unfocused asset number and name becoming blank after `openAsset(..., {keep: true})`. The document itself did not reload and the drawer stayed open. No automatic page reload or service worker was found; the one `location.reload()` is behind an explicit connection-retry button.

The form fields have names but no ids. The existing drawer restoration retained only the focused input with an id, and did not retain the unit panel's open folds. The reports poll redraws an open drawer every 20 seconds, including when the record has not changed. Shared-record, photo registry and photo outbox redraws have the same issue. A retained dirty transport form explicitly continues to say “Unsaved changes”; if its source changed, the stale-source warning takes precedence.

`patch_idle1006.apply(html)` installs `idle1006.js` before the native sync callback and routes those four background refresh paths through it. It retains expanded details, open galleries, scroll position, focused fields/caret and dirty unit/transport-form values. Untouched values still receive current data. A dirty draft keeps its original concurrency tokens, so it cannot silently overwrite a newer unit or transport edit. Form type is part of the stable identity, so a transport draft cannot restore into a unit form even if their reference and document attributes match. Local `bump()` and submit redraw semantics are unchanged: a saved add-unit form still clears. The helper adds no timers, persistent cache, native record changes or reloads.

`check_idle1006.cjs` runs the native phone/desktop background callbacks with every operational network write blocked. It covers the 20-second reports path, shared-record callback, both photo refresh paths, unfocused drafts, focus/caret, fold/gallery/scroll retention, local-form reset, changed-source tokens, clean-field updates, removed forms and closed drawers. The actual GN20 transport editor additionally retains an unsaved rate and note through the native redraw; its native Save refuses the retained stale source token and a read-only link. These tests cannot establish whether Android separately discarded a browser process; that remains outside the reproduced app defect.
