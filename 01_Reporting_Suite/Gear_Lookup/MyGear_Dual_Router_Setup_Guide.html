Getting the QR-at-the-window lookup running on your own router, off the work wifi  |  22 Jul 2026  |  Author: Andrew Fisher  |  POWERED BY SITEIQ
THE CALL
Run My Gear on your own router as a stand-alone island network at the tool store. Phones join your router's wifi to see their gear; the laptop stays on the work wifi for email and SiteIQ pulls. Nothing is ever cabled between the two networks, and the updated launcher serves the page on your router's side only — so nobody on the work network can tap in, and site IT has nothing running on their infrastructure.

The only "link" between the two networks is the laptop itself — and the server is bound so it only answers on the router side.

One-time setup (about 15 minutes)

  1. Power up your router. Leave the Internet/WAN port empty — nothing ever gets plugged into it. That empty port is the whole security story.
  2. Set up its wifi (router's app, or browse to the address on its sticker while connected to it): wifi name e.g. K2 TOOL STORE, a strong WPA2 password, and change the router's admin password while you're in there.
  3. Recommended: in the router settings, give the laptop a reserved / static address (usually under DHCP → address reservation). Then the QR poster address never changes and one printed poster lasts the whole shutdown.
  4. Cable the laptop to the router — laptop into one of the router's LAN ports (a USB-to-ethernet adapter is fine). The laptop's wifi stays on the work network as normal.
  5. If Windows asks about the new network, choose Yes / Private. (If it doesn't ask: Settings → Network & internet → Ethernet → network profile → Private.)
  6. Double-click START_GEAR_LOOKUP.bat. First run, it lists the laptop's networks — pick the router line (the cabled Ethernet/USB one, not the work wifi) and type your wifi name. It saves the choice to MY_GEAR_NETWORK.txt; every morning after that it's automatic.
  7. When Windows Firewall asks about Python, tick Private networks and Allow. (No admin rights? See the IT ask below.)
  8. Print the poster it writes — Gear_Lookup\QR_Window_Poster.html — and stick it at the window.
  9. Test with your own phone: join the K2 TOOL STORE wifi, scan the poster, enter your ID. If your list comes up, you're in business.

Every morning (two minutes)

  1. Pull the fresh SiteIQ exports into the kit folder as usual.
  2. Run the report kit — option G (or --lookup) rebuilds the page with today's on-hire data.
  3. Double-click START_GEAR_LOOKUP.bat and leave the black window open. Closing it stops the site — nothing keeps running behind your back.

Why this is safe to run

  • Island network. Your router touches nothing of the work network — WAN port empty, no bridging, no repeating. There is no path from crew phones to Coates or Cement Australia systems.
  • Served on one side only. The launcher binds the page to your router's address, not to every network on the laptop. From the work wifi, there is nothing to connect to.
  • Private by design. Each person's list is encrypted against their own ID — the page carries no open register, a wrong ID shows nothing, and the screen clears itself after 45 seconds.
  • Runs only while the window's open. End of day, close it — server gone.
  • One Team: worth a quick heads-up to site IT that a stand-alone router runs at the tool store window, not connected to their network. Thirty seconds of courtesy now saves a conversation later.
NEVER DO THESE
  • Never plug your router's Internet/WAN port into a site wall socket or anything on the work network — that's the one move that turns "island" into "tap in".
  • Don't set your router to repeat / extend / bridge the work wifi.
  • Wifi password on a card at the counter is fine — the router's admin password stays with you.

If it plays up

SymptomFix
Phone can't see the K2 TOOL STORE wifiRouter power, and check 2.4 GHz is on — older phones don't see 5 GHz-only.
Phone joined but the page won't loadLaptop cabled into a LAN port (not WAN); firewall allowed on Private; re-run the .bat and check the address it prints matches the poster.
Phone says "no internet" on the wifiNormal — My Gear doesn't need internet. If the phone offers to switch networks, tell it to stay connected.
Poster QR goes to the wrong addressThe laptop got a new address from the router. Set the reservation (setup step 3) — or just print the fresh poster today's run wrote.
Launcher warns the saved network isn't liveRouter off or cable out. Plug in, run again — or pick again from its list.
Firewall prompt never appeared / no admin rightsReady-made ask for IT: "Inbound allow rule: python.exe, TCP 8123, Private profile only — serves a static read-only page to a stand-alone router at the tool store, not connected to the corporate network."
Page loads but says "engine check failed"Rebuild the page — report kit option G — then refresh the phone.
