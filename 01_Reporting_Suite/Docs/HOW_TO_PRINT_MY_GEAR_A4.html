My Gear - set up the printer, print the A4

One-time printer setup (store laptop)

1
Plug the printer's USB into the laptop (or join it to the store Wi-Fi if it's a network printer). Windows will find it by itself - give it a minute.
2
Press Start → type Printers → open Printers & scanners. Click your printer → Set as default.
3
Still in the printer's settings: Printing preferences → paper size A4, orientation Portrait, scale 100%. Done - you never touch this again.

Printing someone's gear page (every day)

1
On My Gear, the person scans their ID (or types it) → their card opens.
2
Press PRINT A4 on their card.
3
The print window opens with the branded A4 document ready - check the preview shows 1-2 pages, press Print. Signed copy goes wherever your process needs it.

If it plays up

?
Blank or half a page: the wrong printer is default - redo setup step 2.
Tiny print / cut off: scale is not 100% or paper is not A4 - redo setup step 3.
Nothing happens: printer is off or out of paper. It is always one of those two. We are here to help - reach out if you need anything.
