The suite is a folder of numbered buttons. Data flows in one direction, and you are the only send button in the system. Here is the entire flow:

The big picture

SiteIQYou export the six morning files — they land in Downloads. RENTAL_STOCK · ON_HIRE · TRANSACTIONS · SALES_STOCK · STOCKTAKE · DAILY_SUMMARY
▼28_PULL_SITEIQ_EXPORTS files them into Data_SiteIQ\ (dated copies kept)

▼35_CHECK_REPORTS reads what was built — flags blanks and broken numbers BEFORE anyone sees them
Outlook DraftsEvery email pre-addressed from the recipients workbook, report pasted in the body, PDFs attached. Sitting. Waiting.
▼you read it like the client will

The morning — three buttons, about 15 minutes

1
28_PULL_SITEIQ_EXPORTS.bat — takes the fresh exports out of Downloads and files them properly.
2
00_RUN_EVERYTHING.bat — builds the lot. (Only want one thing? 37_PICK_A_REPORT.bat instead — 30 seconds.)
3
35_CHECK_REPORTS.bat — run this before you send anything.

Getting an improvement made — the loop

1
Ask Claude in the chat for the change you want — a new report, a colour, a fix, anything.
2
Download the K2_UPDATE zip it sends back. It lands in Downloads — that's fine, leave it there.
3
46_APPLY_UPDATE.bat — finds the zip itself, backs up everything it replaces, never touches your address book / charges / SiteIQ data, and puts everything back automatically if the update is broken. Safe to run twice.
Two laptops? After an update: 39_SYNC_PCS.bat carries it across, 40_WHAT_VERSION_AM_I.bat on both proves they match — same code line = same suite.

The rules of the house

RuleWhy you can trust it
Nothing sends by itselfEverything goes to Drafts and waits for you. 26/27 switch draft-making off/on entirely.
Nothing is guessedNo price, no email address, no hirer ID is ever invented. Missing = TBC or a dash, and the report says so.
Nothing is overwrittenDated folders are append-only; reruns write (2) beside the original. Updates and sync back up before replacing.
Safe to run twiceCharges, contacts, gear additions, update zips — all refuse to double-apply.
The company name ties everythingData, folder and recipient list must match, or the pack is HELD — a DGH report cannot go out on another company's list.
