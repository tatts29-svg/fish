# GC500 page fixes — for the package that builds the page

The page (`GC500_Delivery_Control_hosted-NN.html`) is generated by `print/build_asset_app.py` in the GC500
package; the app script sits in that file verbatim. The service's overlay (`../overlay/`) repairs four faults at
runtime as a bridge. This folder carries the same fixes, plus the ones the overlay could not reach, as edits to
the page's own source, so the next build carries them and the overlay's repairs become no-ops.

```
page-fixes/
  apply.js                 applies the edits to build_asset_app.py (or to a built page) — each must match once
  build_asset_app.patch    the same edits as a unified diff against the v5.25 package's builder (17 Sep 2026)
```

## Apply

In the GC500 package, either

```
node page-fixes/apply.js print/build_asset_app.py       # edits in place, refuses if any anchor is not found once
python3 build_all.py                                    # the package's own build + 48 verify steps
```

or `patch -p0 < page-fixes/build_asset_app.patch` and build. The patch was written against hosted-37 / the
v5.25 update of 17 Sep 2026; on a later builder, run `apply.js` instead — it reports which anchors moved.

## What changes

| # | Where | Fault | Edit |
|---|---|---|---|
| R1 | `renderDocs()` | Every `[data-open]` in a document card was bound to the asset drawer after the thumbnail had been bound to its file, so tapping a drawing's cover opened the drawer with a URL. | The card binding skips `img.thumb`. |
| R2 | `finderPick()` | Removed `search-open` from the body directly; the magnifier kept `aria-expanded="true"` and `SEARCH_FROM` was never reset. | Calls `closeSearch({keepQuery: true, noFocus: true})`. |
| R4 | `recordBytes()` / `persist()` | Read the whole record (up to ~5 MB) out of `localStorage` on every 4 s poll and every footer redraw. | `persist()` records the size as it writes; `recordBytes()` reuses it for 20 s. |
| B1 | `timeOfStamp` | `hour12: false` prints midnight as `24:05` on some ICU builds (the page already guards this in `brisStamp`). | `hourCycle: 'h23'`, as `tpodParts()` uses. |
| B3 | showcase countdown | `kick(esc(name))` — `kick` escapes again, so `&` renders as `&amp;`. | Escaped once. |
| B4 | `photoRedraw()` | Called `render()` while somebody could be typing in the drawer. | Goes through `syncRedraw()`, which waits for typing to stop and reopens the drawer. |
| B5 | `boardWxNote()` | Built HTML-escaped text that the first draw placed as HTML and the refresh placed as text. | Plain text; the first draw escapes it like the refresh. |
| B6 | `adviceSheet()` | `window.print()` after a flat 60 ms. | The font-settled path `paperOpen()` uses. |

Not changed: R3 (`showReduced` honouring Motion: Off) is already in hosted-37. B2 (the scanner burst detector
accepting keys typed in the search box) is left as it is — a fast Enter on a four-character search opens the one
match, which is what a scanner does, and the miss case only moves to the Register with the text as the query.

## Proof

`test/real.js` uploads a built page to the built service and drives it in Chromium on a laptop and a phone.
Run on hosted-37 as delivered and on hosted-37 with these edits applied (`apply.js <page> <out>`), the same
checks pass on both and the page raises no console error of its own; screenshots in `test/out/h37*-*.png`.
